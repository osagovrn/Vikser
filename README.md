# Виксер: сайт компании

Сайт ООО «Фирма Виксер» (Воронеж): главная страница и политика обработки персональных данных.
Стек: TanStack Start, React 19, Tailwind 4, Vite, SSR через Nitro.

## Запуск

    npm install
    npm run dev      # http://localhost:8080
    npm run build    # сборка в .vercel/output
    npm run preview  # локальный просмотр собранной версии
    npm run typecheck
    npm run lint

Нужен Node 20.19+ (в репозитории зафиксирован `.nvmrc` — 24).

## Домен

Сайт **не привязан к домену**. Canonical, `og:url`, `og:image`, `sitemap.xml` и `robots.txt` строятся
от фактического адреса запроса — откройте сайт на любом домене, и метаданные сразу будут правильными.
Правки в коде не нужны.

`VITE_SITE_URL` нужен только если домен надо зафиксировать жёстко (например, сборка складывается
в статику на другой хостинг, где запросов к Node нет).

## Переменные окружения

| Переменная | Зачем | По умолчанию |
|---|---|---|
| `VITE_SITE_URL` | Жёстко задать адрес сайта для canonical и Open Graph | берётся из запроса |
| `VITE_METRIKA_ID` | Номер счётчика Яндекс.Метрики | не задан → аналитики нет |

Пока `VITE_METRIKA_ID` пуст, на сайте нет ни счётчика, ни cookie, ни баннера — это нормально.

## Структура

- `src/routes/index.tsx` — главная страница: шапка, 12 услуг, преимущества, этапы, объекты, лицензии, карта, политика, подвал, форма в модальном окне.
- `src/routes/privacy.tsx` — политика обработки персональных данных.
- `src/routes/robots[.]txt.ts`, `src/routes/sitemap[.]xml.ts` — серверные ответы для поисковиков.
- `src/routes/__root.tsx` — общий каркас документа, шрифты, иконки, cookie-уведомление.
- `src/lib/site.ts` — определение адреса сайта и номер счётчика.
- `src/lib/analytics.ts` — подключение Метрики и цели.
- `src/styles.css` — все стили (дизайн-система + адаптив).

`src/routeTree.gen.ts` генерируется автоматически при сборке, но лежит в репозитории: без него `npm run typecheck` падает на свежем клоне.

## Заявки

Форма не отправляет данные на сервер: она открывает почтовую программу с готовым письмом на `vikser.vrn@ya.ru`. Сайт ничего не сохраняет — это указано в политике.

Цели в Метрике: `open_quote`, `form_submit`, `phone_click`, `email_click`.

## Тексты

Тексты услуг, объектов и реквизитов — в начале `src/routes/index.tsx` (массивы `services` и `projects`). Менять только там, вёрстку не трогать.

## Деплой

Сайт собирается в двух вариантах.

**1. Статика для GitHub Pages** — самый дешёвый вариант: хостинг бесплатный, платить нужно только за домен.

    npm run build:static      # результат в dist-static/

Сборка кладёт `index.html`, `privacy/index.html`, `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`
и все файлы. Пуш в `main` собирает и публикует её workflow `.github/workflows/deploy-pages.yml`.

**Публикация включается доменом.** Пока переменная `SITE_URL` не задана, workflow собирает сайт
с `VITE_BASE_PATH=/Vikser/` и публикует его в подпапке репозитория — так GitHub Pages отдаёт
проектные сайты, когда у аккаунта уже есть свой домен. Как только домен куплен, переменная
меняет базу на корень, и сайт переезжает на `https://ваш-домен.ru/`.

Порядок, когда домен куплен:

1. Settings → Secrets and variables → Actions → Variables → `SITE_URL` = `https://ваш-домен.ru`
   (без слэша на конце).
2. Settings → Pages → Custom domain → тот же домен, сохранить.
3. У регистратора в DNS:

   | Тип | Имя | Значение |
   |---|---|---|
   | A | `@` | `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` |
   | CNAME | `www` | `osagovrn.github.io` |

4. Через 15 минут–час включить «Enforce HTTPS» в настройках Pages — сертификат Let's Encrypt
   выпускается автоматически и бесплатно.

Ограничения бесплатного GitHub Pages: репозиторий до 1 ГБ, трафик ~100 ГБ/мес, сборка до 10 раз в час.
Для сайта-визитки это с запасом в тысячи раз.

**2. Серверный вариант** — `.vercel/output` (Nitro, preset `vercel`): Vercel или Node-хостинг,
запуск `node .output/server/index.mjs`. Кэширование статики и security-заголовки заданы
в `vite.config.ts` (`nitro.routeRules`).
